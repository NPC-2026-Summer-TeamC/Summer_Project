# 606호에 어서오세요 (Welcome to Room 606)

> **15개 타일 퍼즐 기반 스토리 어드벤처 게임**  
> 방 안의 사물과 단서를 이동·배치하여 606호의 숨겨진 이야기를 풀어가는 Unity 2D/3D 프로젝트입니다.

---

## 📌 프로젝트 정보

- **엔진 버전**: `Unity 6000.3.11f1` (Unity 6)
- **렌더 파이프라인**: URP (Universal Render Pipeline)
- **타겟 플랫폼**: PC (Windows)

---

## 🚀 빠른 시작 (Quick Start)

1. 저장소 클론:
   ```bash
   git clone https://github.com/NPC-2026-Summer-TeamC/Summer_Project.git
   ```
2. Git LFS 활성화 및 에셋 동기화:
   ```bash
   git lfs install
   git lfs pull
   ```
3. `Unity Hub`에서 `Unity 6000.3.11f1` 버전으로 프로젝트를 열어 실행합니다.
